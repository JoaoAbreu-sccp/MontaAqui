# MontaAqui

O MontaAqui é uma plataforma web que ajuda qualquer pessoa a montar um computador, mesmo sem entender de hardware. Ela responde a um questionário rápido sobre quanto quer gastar e para que vai usar o PC (jogos, edição, estudo, trabalho), e um assistente com inteligência artificial recomenda até três configurações com peças compatíveis entre si: uma abaixo do orçamento, uma equilibrada e uma acima. Cada peça vem com link de compra, e quem cria uma conta pode salvar as montagens.

Integrantes: Eduardo Barreto, Ícaro Rodrigues e João Vitor Abreu.
